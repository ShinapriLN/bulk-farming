# Bulk Farming (Fabric 1.21.x)

**Bulk Farming** — a lightweight QoL mod that lets you harvest and re-plant large farmland areas fast without lag.

* **Simple controls:** hold **Shift** + **LMB(left mouse button) with a hoe** to harvest, **RMB with seeds** to plant.
* **Smart + safe:** only targets fully-grown crops on **farmland**; skips if inventory can’t fit drops—no item loss.
* **Supported crops:** wheat, carrots, potatoes, etc.
* **Configurable:** toggle collect-to-inventory.
